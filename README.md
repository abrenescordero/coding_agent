# Sistema Solar Animado

Proyecto creado con **Vite + React + TypeScript**.

Incluye una página principal con un sistema solar animado que muestra:

- El Sol en el centro
- Las órbitas de los planetas
- Los 8 planetas orbitando con distintas velocidades
- Una leyenda con los nombres de los planetas

## Scripts

- `npm run dev`: iniciar servidor de desarrollo
- `npm run build`: generar build de producción
- `npm run lint`: ejecutar linter
